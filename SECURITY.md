# Security Policy

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately to the repository
maintainers through GitHub Security Advisories:

https://github.com/RooAGI/red-green-proof/security/advisories/new

Please include the affected file or version, a description of the impact, and
reproduction steps when possible. Do not disclose the issue publicly until the
maintainers have had an opportunity to investigate and coordinate a fix.
